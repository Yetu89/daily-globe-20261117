THE DAY IN WORLD NEWS — one image that sums up the world's news of Tuesday 17 November 2026: 40 stories across 6 continents, drawn as a single 1024×1024 newspaper front page. Template merged from the contest's 5 top-ranked entries: dark navy masthead, 2 heroes, 12 illustrated stories, a numbered world map and a numbered "Also on" list. Lead stories: Ukraine hits the Crimea bridge for a second day; Iran drones target a US radar in Bahrain. The image is drawn offline by `tools/build_image.py` from the checked stories in `tools/stories.json` and shipped as `entry.png`; `main.py` copies it to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
